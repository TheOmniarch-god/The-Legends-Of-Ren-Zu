# Stage 4 Visual Parity Notes

This overlay keeps the SEO/search layer but redesigns its UI to feel much closer to the main Omniarch site.

## What changed
- Switched the support pages from the dark palette to the Omniarch paper / ink / seal palette
- Added the same font family stack used on the main site:
  - Unbounded
  - Space Grotesk
  - Inter
  - Fragment Mono
- Reworked cards, buttons, hero sections, chips, navigation, and section blocks
- Preserved all Stage 3 SEO pages and internal linking
- Kept the immersive reader untouched

## Goal
The support pages now feel like part of the same world instead of a separate dark microsite.
