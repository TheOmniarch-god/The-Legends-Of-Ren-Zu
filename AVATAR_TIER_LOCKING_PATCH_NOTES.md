# Avatar Tier Locking Patch

Changed file:

- `index.html`

## What changed

- Added tier requirements to default avatars.
- Free/Mortal users have a starter set.
- Gu Master unlocks extra avatars.
- Gu Immortal unlocks higher avatars.
- Venerable unlocks legendary avatars.
- `The Legend` is Venerable-only.
- Locked avatars are visible but dimmed and marked with a lock.
- Tapping a locked avatar shows the required realm and does not select it.
- If an old selected avatar is now locked for the current realm, the app falls back to an unlocked default automatically.
