# Stage 6 Legends UX Refinement Notes

This pass responds directly to the latest visual feedback.

## What changed
- Menu button simplified to just `Menu` (no 3 horizontal strokes)
- Mobile nav remains compact instead of turning into a huge static block
- Header still hides on scroll down for reading comfort
- Gold / Omniarch-like eyebrow styling was reduced and neutralized
- Click targets in cards and footer now sit in clearer canvases so they read as links
- Spacing tightened across cards, chips, actions, and hero layout
- Hero image is no longer forced on mobile once the compact menu is enough
- Desktop can still retain the Ren Zu hero visual if desired

## Intent
This pass should feel less like The Omniarch and more like a cleaner companion to the Legends site itself.
