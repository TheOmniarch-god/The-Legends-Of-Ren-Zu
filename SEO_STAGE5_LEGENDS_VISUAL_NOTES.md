# Stage 5 Legends Visual Alignment Notes

This overlay corrects the design direction after Stage 4.

## The correction
The previous pass leaned too much toward the main Omniarch site.
This new pass aims much closer to the visual language of the live Legends of Ren Zu site instead.

## What changed
- Support pages now use a Legends-style warm parchment palette instead of the stronger Omniarch paper/seal feel
- Typography changed to a more Legends-style stack:
  - IM Fell English
  - EB Garamond
  - Poppins
  - Cinzel Decorative
- Added compact mobile-first header with a menu button instead of a giant always-open nav block
- Header now hides on downward scroll and reappears when scrolling up
- Added the Legends hero image (`/assets/renzu-main-app-image.jpg`) into the page hero area
- Kept all Stage 3 SEO/support content and internal linking
- Kept the immersive reader untouched

## Intent
Closer to the Ren Zu site itself, not the Omniarch homepage.
